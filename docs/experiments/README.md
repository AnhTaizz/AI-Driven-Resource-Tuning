# Experiment Records

Create one record per benchmark/model experiment using `EXPERIMENT_TEMPLATE.md`.

Naming convention:

```text
EXP-0001-short-description.md
EXP-0002-short-description.md
```

Do not overwrite old records to make later results look cleaner. If an experiment is invalid, keep the record and mark the invalidation reason.

Recommended status values:

- PLANNED
- RUNNING
- COMPLETED
- FAILED
- INVALIDATED

An experiment record is evidence, not marketing. Preserve negative outcomes.
